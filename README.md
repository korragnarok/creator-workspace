# Creator Desk

A lightweight creator organization workspace for TikTok Shop creators.

## Current Scope

- Dashboard overview
- Daily todo
- Hook Bank
- Product Bank
- Script Vault
- Sample data only
- No AI features
- No Notion integration
- No commission tracking
- No sales analytics

## Development Plan

1. Static prototype with the core screens and sample data.
2. Local storage MVP with add, edit, delete, search, and filters.
3. Design pass for colors, fonts, spacing, and tone.
4. Optional Supabase migration only if accounts or cross-device sync become necessary.

## Run Locally

```bash
npm run dev
```

Then open http://localhost:3000.
